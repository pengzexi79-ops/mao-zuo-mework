## 1. 重构工作流页面为中文向导

修改：

- `frontend/src/views/Workflows.vue`

## 7. Hyperframes 与 Remotion 可选模块

### Hyperframes

新增隔离 `HyperframesIntroService`，默认关闭，只负责生成本地片头 MP4；失败回退普通片头，不影响 FFmpeg 主链路。

### Remotion

作为独立 Node 渲染目录/服务，仅生成可选标题卡、动态字幕、片头片尾 MP4；不可用时不影响主混剪流程。
