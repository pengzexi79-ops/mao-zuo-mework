**一、每个编号的唯一合法格式**

从编号到下一个编号、章节标题、分隔线或终章之间，严格只允许 3 行非空内容：

```text
3
动作/神态：老周脸涨得通红，双手撑住椅背；老赵停在门口，紧紧攥着药袋。
老周：我不用你们扶，我自己能站起来！
```

不允许出现任何额外台词行、角色标签、旁白、画外音、电话消息或引号里的可念台词。

**二、硬性单人规则**

- 第 1 行只能是连续编号。
- 第 2 行必须以 `动作/神态：` 开头，只写无台词、可拍的动作、表情、眼神、道具和其他人物的无声反应。
- 动作行禁止出现第二个冒号、引号、角色名加冒号，以及“说、问、答、喊、叫、念、道、回应”等引出台词的写法。
- 第 3 行只能是 `唯一角色名：一句台词` 或 `旁白：一句台词`。
- 第 3 行只能有一个角色标签、一个冒号和一句完整台词；台词不能换行，不能含另一角色台词、引号里的转述、第二句或插话。
- `旁白`、`画外音`、电话内容、消息内容均算唯一说话者；出现它们时，该编号不能有任何角色发言。
- 其他人物只能在动作行沉默反应。任何回应都必须拆到下一个连续编号。

**三、将你截图里的错误形式自动拆分**

当前错误形式：

```text
3

老赵：老周，你别逞强，坐下歇歇。

4
动作/神态：老周抬手挡开老赵，腰一挺又疼得弯下去；刘大炮站在门边，冷眼看着。
老周：我没事，我自己能站起来！

5
动作/神态：刘大炮抱起胳膊，往前一步；老赵扶住老周的胳膊，没有开口。
刘大炮：你这腰都直不起来了，还硬撑什么？
```

**四、输出前的逐编号强制自检**

AI 每次生成后，在内部逐条检查：

1. 每个编号是否恰好只有“编号、动作/神态、唯一台词”三行非空内容。
2. 动作行是否没有台词、引号、第二个冒号、角色发言标签或引出台词的动词。
3. 台词行是否只有一个说话角色、一个冒号和一句话。
4. 是否任何回应、插话、旁白、画外音、电话或消息内容都被拆到下一个连续编号。
5. 任意一项不符合，就在发送前自动拆成多个连续编号。
